# Student Management Dashboard

A simple and beginner-friendly Student Management Dashboard built using React JS, React Bootstrap, and Redux. The project allows users to manage student records through a clean and responsive interface.

## Features

* Student Dashboard
* Add Student Record
* Display Student Records
* Search Student Records
* Empty Record State
* Filled Record State
* Form Validation
* Redux State Management
* Responsive UI

## Technologies Used

* React JS
* JavaScript
* HTML
* CSS
* React Bootstrap
* Redux Toolkit
* Vite

## Project Structure

```text
src/
├── components/
│   ├── Form.jsx
│   ├── StudentList.jsx
│   └── ...
├── redux/
│   └── studentSlice.js
├── App.jsx
├── main.jsx
└── index.css
```

## Installation

First, open the project folder in the terminal and install the required packages.

```bash
npm install
```

## Run the Project

Start the development server using:

```bash
npm run dev
```

Then open the local URL shown in the terminal in your browser.

## Dashboard

The dashboard is the main page of the application. It provides a simple interface for managing and viewing student records.

## Empty Record

When there are no student records available, the application displays an empty-record message to the user.

## Filled Record

After adding student information, the records are displayed in the student list.

## State Management

Redux Toolkit is used to manage the student data and application state.

## Responsive Design

The application is designed to work on different screen sizes, including desktop, tablet, and mobile devices.

## Conclusion

This project demonstrates a simple Student Management Dashboard using React JS, React Bootstrap, and Redux. The project uses a beginner-friendly structure and provides a clean interface for managing student records.
